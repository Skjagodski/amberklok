AMBERKLOK - PUBLICEREN MET GITHUB PAGES

1. Maak op github.com een nieuwe openbare repository, bijvoorbeeld amberklok.
2. Upload index.html en manifest.webmanifest in de hoofdmap.
3. Ga naar Settings > Pages. Kies Deploy from a branch, branch main en map /(root). Klik Save.
4. Na publicatie: https://GEBRUIKERSNAAM.github.io/amberklok/
5. Open deze link in Safari op de iPhone, tik Deel > Zet op beginscherm.

Let op: een openbare GitHub Pages-site is voor iedereen met de link bereikbaar.
